# Research Tools Assignment

## Use of dataset for statistical analysis
This project uses Palmer Penguine Dataset [https://allisonhorst.github.io/palmerpenguins/] publicly available at https://raw.githubusercontent.com/allisonhorst/palmerpenguins/main/inst/extdata/penguins.csv to be used.

Anyone can use the dataset to learn the statistical analysis using jupyter notebook or google colab, and plot graphs using matplotlib which is being done here.
